# 캐릭터 구상 (5단계)

2026-10-15 작성. SPEC §4-1 의 캐릭터 3종(냠냠이·포동이·반짝이)을 지금 그림체(바람 우체국 v7 · 바다 왕국 · 우주 외계인 마을)에 맞춰 구체화한 안이다. 그림은 Codex 에게 맡길 예정(지시서 초안 `C:/dev/_backup/nyamnyam-garden-v3/CODEX_BRIEF_v10.md`).

## 원칙

- **캐릭터와 테마는 따로 고른다.** 세 캐릭터 모두 세 테마 어디에나 선다(캐릭터 자리·말풍선 자리는 모든 테마 공통: 가로 `translate(250 559) scale(1.13)`, 세로 `translate(145 830) scale(1.1)`).
- 그래도 캐릭터마다 **잘 어울리는 테마(단짝 테마)** 가 하나씩 있다. 테마 선택 화면에서 캐릭터를 고르면 단짝 테마 카드를 맨 앞에 둔다(강요하지 않음).
- 그림체는 냠냠이 v7 기준: 큰 머리(머리:몸 ≈ 1:1), 하이라이트 두 개 있는 큰 눈, 볼터치, 짧은 몸, 진한 외곽선, 높은 채도. 몸짓 5가지 `hello / point / wonder / celebrate / wait` 와 같은 애니메이션 규칙(전환 0.56초, 숨쉬기·깜빡임·흔들기·점프·흔들흔들, `prefers-reduced-motion` 정지).
- 말할 때 입이 움직인다(`mouth` 슬롯, 냠냠이와 같은 방식).
- 유명 캐릭터와 닮지 않게(아래 캐릭터별 "피할 것").

## 캐릭터

|                    | 냠냠이                        | 포동이                            | 반짝이                                         |
| ------------------ | ----------------------------- | --------------------------------- | ---------------------------------------------- |
| 정체               | 아기 병아리                   | 아기 곰                           | 누나 별                                        |
| 단짝 테마          | 바람 우체국                   | 바다 왕국                         | 우주 외계인 마을                               |
| 성격               | 밝고 귀여운 메인, 호기심 많음 | 씩씩하고 듬직한 친구, 조금 느긋함 | 다정하게 칭찬해 주는 누나                      |
| 목소리(클로바더빙) | 다인(아동 여)                 | 하준(아동 남)                     | 아라(어른 여)                                  |
| 말투               | 짧은 감탄, "~했어!", "냠냠!"  | 힘찬 반말, "~다!", "내가 ~할게!"  | 부드러운 누나 말투, "~했구나~", "정말 멋지다~" |

### 냠냠이 (지금 있음)

- 노란 병아리, 주황 부리·발, 큰 갈색 눈. 지금 그림 그대로.
- 단짝 테마 소품(선택): 없음. 메인 캐릭터라 맨몸 그대로가 가장 알아보기 쉽다.

### 포동이 — 아기 곰

- 몸: 꿀빛 갈색(#c98a4b 계열), 크림색 주둥이와 배, 둥근 귀 안쪽은 분홍. 통통한 팔다리, 짧은 꼬리.
- 얼굴: 냠냠이와 같은 하이라이트 눈(조금 더 동그랗게), 작은 진갈색 코, 볼터치, 웃는 입.
- 단짝 소품: 작은 **파란 선원 모자**(바다 왕국과 어울림, 다른 테마에서도 그대로 써도 어색하지 않음). 모자는 몸짓 전환 때 머리와 함께 움직임.
- 몸짓: `hello` 한 손 크게 흔들기, `point` 짧은 팔로 가리키기, `wonder` 두 손 볼에 대고 "우와", `celebrate` 두 팔 번쩍 + 통통 점프, `wait` 앉아서 배 두드리며 흔들흔들.
- 피할 것: 하얀 북극곰(뽀로로 '포비'와 겹침, 이름도 비슷), 가슴의 노란 원(리락쿠마), 무표정한 갈색 곰 얼굴(라인 '브라운'), 빨간 셔츠(곰돌이 푸).

### 반짝이 — 누나 별

- 몸: 끝이 둥근 오각별. 크림 노랑에서 복숭아빛으로 내려가는 그라데이션, 진한 금빛 외곽선. 위쪽 끝은 머리, 양옆 끝은 팔, 아래 두 끝은 다리처럼 쓴다.
- 얼굴: 별 가운데에 큰 하이라이트 눈, 위로 짧은 속눈썹 세 가닥(누나 느낌), 볼터치, 웃는 입.
- 단짝 소품: 머리 끝의 **작은 혜성 꼬리 리본**(분홍~보라). 주변을 도는 작은 반짝이 두세 개(계속 움직이는 요소).
- 몸짓: `hello` 팔 끝을 흔들며 살짝 기울기, `point` 팔 끝으로 가리키며 반짝, `wonder` 몸이 빙그르 반 바퀴, `celebrate` 크게 반짝이며 점프 + 주변 반짝이 터짐, `wait` 둥실둥실 위아래로 떠 있기.
- 피할 것: 점 두 개만 있는 노란 별 얼굴(마리오 '치코/루마'), 분홍 공 모양(커비), 별 위에 탄 캐릭터.

## 대사 (캐릭터 × 말투)

대사는 `content/lines.ts` 에 캐릭터별로 모두 둔다(인사·안내·기다림·터치 등 공통 17키 + 테마별 단계 응원 3테마 × 8줄). 클로바더빙은 줄마다 녹음하므로 캐릭터당 약 45줄.

같은 순간을 세 캐릭터가 말하면 이렇게 다르다(예시 — 확정 아님):

| 순간       | 냠냠이                 | 포동이                      | 반짝이                             |
| ---------- | ---------------------- | --------------------------- | ---------------------------------- |
| 인사       | 안녕! 나는 냠냠이야!   | 안녕! 나는 포동이다!        | 안녕~ 나는 반짝이 누나야.          |
| 기다림     | 천천히 먹어도 괜찮아~  | 천천히 먹자! 내가 기다릴게! | 천천히 먹어도 돼, 누나가 기다릴게~ |
| 바다 3단계 | 조개 궁전이 생겼어!    | 우와, 조개 궁전이다!        | 조개 궁전이 생겼구나~              |
| 우주 7단계 | 로켓에 불이 켜졌어!    | 로켓 발사 준비 완료다!      | 로켓에 불이 켜졌네, 멋지다~        |
| 배불러요   | 배부르구나! 잘 먹었어! | 배부르구나! 잘 먹었다!      | 배불렀구나, 정말 잘 먹었어~        |

규칙(SPEC §12 그대로): 칭찬과 기다림만, 재촉·비교·몸 이야기 금지, 25자 이내, 변수 없음.

## 화면 흐름 (제안)

1. 시작 화면: "누구랑 먹을까?" — 캐릭터 3명 큰 얼굴 카드(누르면 그 캐릭터 목소리로 짧은 인사).
2. "오늘은 어디로 놀러 갈까?" — 테마 카드 3장(고른 캐릭터의 단짝 테마가 맨 앞), 카드 미리보기에 고른 캐릭터가 서 있음.
3. 부모 설정(6단계)에서 "아이가 직접 고르기" 를 끄면 1·2를 건너뛰고 부모가 정한 조합으로 바로 시작.
