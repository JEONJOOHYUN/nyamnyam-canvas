# 캐릭터 구상 (5단계)

2026-10-15 작성. SPEC §4-1 의 캐릭터 3종을 지금 그림체(바람 우체국 v7 · 바다 왕국 · 우주 외계인 마을)에 맞춰 구체화한 안이다. 그림은 Codex 에게 맡긴다(지시서 `C:/dev/_backup/nyamnyam-garden-v3/CODEX_BRIEF_v10.md`).

2026-10-15 사용자 결정: SPEC 의 포동이(곰) 대신 바다에 어울리는 **아기 해달 퐁당이**. 분위기는 "보노보노 같은 해달 + 티니핑 같은 귀여움" — 둘 다 **귀여움의 정도만 참고**하고 생김새는 가져오지 않는다. 반짝이(누나 별)는 그대로 확정.

## 원칙

- **캐릭터와 테마는 따로 고른다.** 세 캐릭터 모두 세 테마 어디에나 선다(캐릭터 자리·말풍선 자리는 모든 테마 공통: 가로 `translate(250 559) scale(1.13)`, 세로 `translate(145 830) scale(1.1)`).
- 그래도 캐릭터마다 **잘 어울리는 테마(단짝 테마)** 가 하나씩 있다. 테마 선택 화면에서 캐릭터를 고르면 단짝 테마 카드를 맨 앞에 둔다(강요하지 않음).
- 그림체는 냠냠이 v7 기준: 큰 머리(머리:몸 ≈ 1:1), 하이라이트 두 개 있는 큰 눈, 볼터치, 짧은 몸, 진한 외곽선, 높은 채도. 몸짓 5가지 `hello / point / wonder / celebrate / wait` 와 같은 애니메이션 규칙(전환 0.56초, 숨쉬기·깜빡임·흔들기·점프·흔들흔들, `prefers-reduced-motion` 정지).
- 말할 때 입이 움직인다(`mouth` 슬롯, 냠냠이와 같은 방식).
- 유명 캐릭터와 닮지 않게(아래 캐릭터별 "피할 것").

## 캐릭터

|                    | 냠냠이                        | 퐁당이                                 | 반짝이                                         |
| ------------------ | ----------------------------- | -------------------------------------- | ---------------------------------------------- |
| 정체               | 아기 병아리                   | 아기 해달                              | 누나 별                                        |
| 단짝 테마          | 바람 우체국                   | 바다 왕국                              | 우주 외계인 마을                               |
| 성격               | 밝고 귀여운 메인, 호기심 많음 | 해맑은 장난꾸러기, 느긋하고 잘 웃음    | 다정하게 칭찬해 주는 누나                      |
| 목소리(클로바더빙) | 다인(아동 여)                 | 하준(아동 남)                          | 아라(어른 여)                                  |
| 말투               | 짧은 감탄, "~했어!", "냠냠!"  | 신나는 반말, 의성어 "퐁당!", "둥실둥실~" | 부드러운 누나 말투, "~했구나~", "정말 멋지다~" |

### 냠냠이 (지금 있음)

- 노란 병아리, 주황 부리·발, 큰 갈색 눈. 지금 그림 그대로.
- 단짝 테마 소품(선택): 없음. 메인 캐릭터라 맨몸 그대로가 가장 알아보기 쉽다.

### 퐁당이 — 아기 해달

- 몸: 따뜻한 라떼 갈색(#b07a4f 계열), 통통한 몸, 짧은 앞발, 넓적하고 끝이 둥근 꼬리(몸 옆으로 보임). 작고 둥근 귀.
- 얼굴: 눈 위에서 주둥이까지 크림색(해달의 밝은 얼굴), 그 안에 **아주 큰 반짝 눈**(하이라이트 두 개 + 눈 아래쪽에 연한 하늘색 반사 — 티니핑 정도의 반짝임), 작은 둥근 코(진갈색, 하이라이트 하나), 볼터치, 웃는 ω 입. 수염은 짧은 선 2가닥씩(점 X).
- 단짝 소품: 머리 한쪽의 **파스텔 분홍 가리비 머리핀**(진주 하나). 몸짓 전환 때 머리와 함께 움직임.
- 몸짓:
  - `hello` 한 앞발 흔들기 + 꼬리 살랑
  - `point` 앞발로 가리키기, 몸을 그쪽으로 살짝 기울임
  - `wonder` 두 앞발로 볼을 감싸며 눈 크게 "우와"(해달이 얼굴 감싸는 몸짓)
  - `celebrate` 두 팔 번쩍 만세 + 통통 점프(팔을 위로 흔듦). 가슴 앞 박수는 앞발이 겹쳐 팔짱처럼 보여서 바꿈
  - `wait` 앉아서 작은 조개를 배 위에 안고 흔들흔들(해달이 배 위에 조개를 올리는 습관)
- 피할 것:
  - 보노보노: 하늘색 몸, 점 같은 작은 눈, 하얗고 큰 주둥이에 검은 점 두 개, 늘 가슴 앞에 든 조개, 땀방울 표현.
  - 티니핑: 특정 캐릭터 생김새(하츄핑의 분홍 하트 머리·작은 날개 등), 이마의 보석, 이름 끝 "-핑". 가져오는 건 큰 반짝 눈·파스텔·작은 장신구 수준만.
  - 실제 해달 사진 같은 사실적인 털 질감.

### 반짝이 — 누나 별

- 몸: 끝이 둥근 오각별. 크림 노랑에서 복숭아빛으로 내려가는 그라데이션, 진한 금빛 외곽선. 위쪽 끝은 머리, 양옆 끝은 팔, 아래 두 끝은 다리처럼 쓴다.
- 얼굴: 별 가운데에 큰 하이라이트 눈, 위로 짧은 속눈썹 세 가닥(누나 느낌), 볼터치, 웃는 입.
- 단짝 소품: 머리 끝의 **작은 혜성 꼬리 리본**(분홍~보라). 주변을 도는 작은 반짝이 두세 개(계속 움직이는 요소).
- 몸짓: `hello` 팔 끝을 흔들며 살짝 기울기, `point` 팔 끝으로 가리키며 반짝, `wonder` 몸이 빙그르 반 바퀴, `celebrate` 크게 반짝이며 점프 + 주변 반짝이 터짐, `wait` 둥실둥실 위아래로 떠 있기.
- 피할 것: 점 두 개만 있는 노란 별 얼굴(마리오 '치코/루마'), 분홍 공 모양(커비), 별 위에 탄 캐릭터.

## 대사 (캐릭터 × 말투)

대사는 `content/lines.ts` 에 캐릭터별로 모두 둔다(인사·안내·기다림·터치 등 공통 17키 + 테마별 단계 응원 3테마 × 8줄). 클로바더빙은 줄마다 녹음하므로 캐릭터당 약 45줄.
